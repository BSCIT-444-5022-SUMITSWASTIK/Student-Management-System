# Student-Management-System
It is a web-based Student Management System to automate academic and administrative processes. Implemented role-based access for Admin, Teacher, and Student, enabling efficient management of student records, attendance, courses, marks, and results.

Built using Java (Servlets & JSP) with MVC architecture, ensuring clean separation of logic, UI, and data handling. Integrated database operations for secure data storage and retrieval, including CRUD functionalities.

Key features include attendance tracking, marks and grade calculation, result generation, and student performance reports, improving efficiency and reducing manual effort in educational institutions.
